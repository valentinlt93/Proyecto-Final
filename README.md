# Validador de tarjetas

Proyecto web sencillo para practicar la validación del algoritmo de Luhn. La página reconoce Visa, Mastercard y American Express, muestra una tarjeta de ejemplo y explica si el número ingresado pasa las comprobaciones.

## Cómo usarlo

1. Descarga o abre la carpeta del proyecto.
2. Abre `index.html` en un navegador.
3. Escribe un número de prueba y selecciona **Verificar tarjeta**.

No necesitas instalar programas ni dependencias.

## Archivos del proyecto

- `index.html`: contiene la página, la tarjeta de ejemplo y el formulario.
- `styles.css`: define los colores, tamaños, diseño y adaptación a pantallas pequeñas.
- `javascript.js`: limpia lo que se escribe, reconoce la marca y valida el número con Luhn.

## Importante

La comprobación es educativa: solo revisa la marca, la longitud y el algoritmo de Luhn. No confirma que una tarjeta sea real, esté activa o pueda realizar pagos. El número se procesa en el navegador y no se envía a un servidor. Usa únicamente números de prueba; no ingreses datos de tarjetas reales.
